# Flow — игровой лобби-сервер

Учебный лобби-сервер для мобильной онлайн-игры на Python (только стандартная библиотека, Python 3.10+).
Свой собственный протокол — никакого кода или данных чужих игр.

## Что умеет

- TCP-сервер на `asyncio`, пакеты с заголовком `| ID u16 | длина u32 | версия u16 | данные |`
- Вход: новый аккаунт (`id=0`) или повторный вход по `id + token`
- Профиль: имя, монеты, гемы, трофеи, предметы (SQLite)
- Магазин: цены хранятся только на сервере, покупка атомарная
- Защита: лимит размера пакета, таймаут простоя, запрет запросов без входа, запрет двойного входа

## Запуск

```bash
python -m server.server --port 7777 --db game.db   # сервер
python -m client.client --port 7777                 # тестовый клиент (в другом терминале)
python -m unittest discover -s tests -t . -v        # тесты
```

## Структура

| Файл | Что внутри |
|---|---|
| `server/protocol.py` | формат пакета, `Writer`/`Reader` для полей |
| `server/messages.py` | ID сообщений и коды результатов |
| `server/database.py` | аккаунты и инвентарь в SQLite |
| `server/server.py` | сессии, обработчики сообщений, магазин |
| `client/client.py` | консольный клиент |
| `tests/test_server.py` | сквозные тесты |

## Как добавить новое сообщение

1. Добавить ID в `server/messages.py`.
2. Написать метод `on_...` в `Session` (`server/server.py`) и зарегистрировать его в `HANDLERS`.
3. Добавить метод в `client/client.py` и тест в `tests/test_server.py`.
