# Flow — игровой лобби-сервер

Учебный лобби-сервер для мобильной онлайн-игры на Python (только стандартная библиотека, Python 3.10+).
Свой собственный протокол — никакого кода или данных чужих игр.

## Что умеет

- TCP-сервер на `asyncio`, пакеты с заголовком `| ID u16 | длина u32 | версия u16 | данные |`
- Вход: новый аккаунт (`id=0`) или повторный вход по `id + token`
- Профиль: имя, монеты, гемы, трофеи, предметы (SQLite)
- Магазин: цены хранятся только на сервере, покупка атомарная
- Матчмейкинг: очередь, подбор комнаты (по умолчанию 3 на 3), отмена поиска
- Боевой сервер на UDP: 20 тиков в секунду, движение, стрельба, урон, победа по выбыванию или по времени
- Трофеи за бой: победа +8, поражение −4 (не ниже нуля)
- Защита: лимит размера пакета, таймаут простоя, запрет запросов без входа, запрет двойного входа

## Запуск

```bash
python -m server.server --port 7777 --battle-port 7778 --db game.db   # сервер
python -m client.client --port 7777                                   # тестовый клиент (в другом терминале)
python -m unittest discover -s tests -t . -v        # тесты
```

Чтобы проверить бой в одиночку, запустите сервер с `--match-size 2` и два клиента
с разными файлами сохранения (`--save a.json` и `--save b.json`), в обоих выберите «4) Бой» —
за вас сыграют боты.

Если клиенты подключаются с других устройств, укажите серверу `--public-host <ваш IP>`:
этот адрес клиенты получат для подключения к боевому серверу.

## Как проходит бой

```
Клиент ──TCP──► Лобби: START_MATCHMAKING
Лобби: набралось игроков → создаёт комнату, каждому MATCH_FOUND (адрес UDP, секретный билет, слот, команда)
Клиент ──UDP──► Боевой сервер: JOIN(билет), потом INPUT(движение, выстрел, угол) каждый тик
Боевой сервер ──UDP──► STATE 20 раз в секунду, в конце END(победитель)
Лобби ──TCP──► BATTLE_RESULT (исход, изменение трофеев)
```

Клиент присылает только ввод. Позиции, попадания и урон считает сервер. Ввод принимается
только с адреса, с которого пришёл JOIN, старые UDP-пакеты отбрасываются по номеру `seq`.

## Структура

| Файл | Что внутри |
|---|---|
| `server/protocol.py` | формат пакета, `Writer`/`Reader` для полей |
| `server/messages.py` | ID сообщений и коды результатов |
| `server/database.py` | аккаунты и инвентарь в SQLite |
| `server/server.py` | сессии, обработчики сообщений, магазин, матчмейкинг |
| `server/battle.py` | симуляция боя (`Room`) и UDP-сервер (`BattleServer`) |
| `client/client.py` | консольный клиент, UDP-клиент боя, бот |
| `tests/test_server.py` | тесты лобби |
| `tests/test_battle.py` | тесты симуляции и полного матча |

## Как добавить новое сообщение

1. Добавить ID в `server/messages.py`.
2. Написать метод `on_...` в `Session` (`server/server.py`) и зарегистрировать его в `HANDLERS`.
3. Добавить метод в `client/client.py` и тест в `tests/test_server.py`.
